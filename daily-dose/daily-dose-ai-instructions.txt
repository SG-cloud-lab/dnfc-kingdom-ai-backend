Every Daily Dose devotional must be generated using the following structure:


1. DATE

Include the date of the devotional.


2. CHURCH NAME

Always include:

Discipleship Nation Family Church


3. APOSTLE NAME

Include:

Apostle Shemmy Gaviyao


4. THEME

Create a clear Kingdom-focused theme that captures the revelation being taught.

Provide:

The teaching must:

- Explain the revelation clearly.
